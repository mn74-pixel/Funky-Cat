# Funky-Cat

Gra przeglądarkowa „Funky Cat na różowo” z muzyką Marcina Nowakowskiego.

## Uruchamianie

Gra i osadzone zasoby znajdują się w pliku `index.html`. Projekt nie wymaga instalacji zależności ani kompilacji.

## Publikacja

GitHub Pages publikuje katalog główny (`/`) gałęzi `main`, z ustawieniem **Deploy from a branch**. Plik `.nojekyll` umożliwia publikację statycznej strony bez przetwarzania Jekyll.

Po poprawnym wdrożeniu gra powinna być dostępna pod adresem:

https://mn74-pixel.github.io/Funky-Cat/

Stan publikacji można sprawdzić w zakładce **Actions** oraz **Settings → Pages** repozytorium.
